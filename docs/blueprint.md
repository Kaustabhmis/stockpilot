# **App Name**: StockPilot

## Core Features:

- Dashboard: Dashboard providing at-a-glance view of stock levels, purchase recommendations, and kitting analysis.
- Tabular Data Display: Tabular views for materials, kits, stock movements and sales.
- Data Input Forms: Interactive forms to add, modify, and manage materials and kits.
- Real-time Monitoring: Real-time stock level monitoring with color-coded status indicators.
- Automated Reorder Calculations: Calculation of reorder points based on safety stock levels and lead times.
- AI Purchase Recommendations: AI-powered purchase recommendations to tool generate purchase orders based on stock levels and demand forecasts.
- Sales Recording: Sales recording interface

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to evoke trust, stability, and organization.
- Background color: Light gray (#F0F2F5) to provide a clean and neutral backdrop, ensuring readability and focus.
- Accent color: Vivid orange (#FF9800) to draw attention to key actions, alerts, and interactive elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a modern, machined, objective, neutral look; suitable for both headlines and body text.
- Use clean and simple line icons from a consistent set to represent common actions and data points.
- Maintain a clear and structured layout using a grid system with consistent spacing and padding.
- Employ subtle animations to provide feedback on user interactions, such as loading states and transitions.
